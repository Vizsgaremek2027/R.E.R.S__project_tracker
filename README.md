# Vizsgaremek projekt követő 


A könyvtárszerkezetben lévő dokumentációkba jegyezzük fel minden lehetséges tényezőt amiből áll a projekt, az átláthatóság kedvéért.
Minden könyvtárban található egy md kiterjesztésű fájl ami vagy tájékoztató jellegű, vagy feljegyzünk benne bizonyos dolgokat magunknak.

#### A könyvtárszerkezet:

```text
├── Backend/
│   ├── Endpoints/
│   └── laravel_folder_system_follower/
├── Database/
│   ├── Dia/
│   ├── Scripts/
│   └── Tables/
├── developer_documentation/
├── Frontend/
│   ├── angular_folder_system_follower/
│   ├── CSS/
│   ├── HTML/
│   └── TypeScript/
├── Github/
│   ├── Branches/
|   |        |── backend_branches/
|   |        |── frontend_branches/
│   ├── Commits/
|   |        |── backend_commits/
|   |        |── frontend_commits/
├── Tests/
│   ├── Playwright/
│   └── testing_sheets/
└── user_documentation/
```
